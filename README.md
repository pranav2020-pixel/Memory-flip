# Memory-flip Game
A simple and interactive memory card flip game built with HTML, CSS, and JavaScript, where players flip cards to find matching pairs. The game uses CSS for smooth flip animations and JavaScript to handle game logic, card matching, and score or move tracking, helping improve memory and concentration.


##**Live Demo:**  
https://pranav2020-pixel.github.io/Memory-flip/

---

##  How to Play

- Click on a card to flip it.
- Flip two cards at a time.
- If the cards match, they remain face-up.
- If the cards do not match, they flip back.
- Match all pairs to win the game.
- Click **Restart** to start a new game.

---

##  Features

- Card flip animation  
- Randomized card shuffle  
- Score tracking  
- Timer  
- Restart button  
- Responsive design  

---

##  Technologies Used

- **HTML** – Structure of the game  
- **CSS** – Styling and animations  
- **JavaScript** – Game logic and interactions
